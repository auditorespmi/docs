---
title: "Cara Mengakses Aplikasi"
description: "Panduan langkah demi langkah untuk mengakses aplikasi eSPMI melalui peramban, termasuk URL login, kredensial pengguna, dan persyaratan jaringan kampus."
---

Langkah-langkah untuk mengakses aplikasi eSPMI:
1. Buka browser Anda.
2. Masukkan URL aplikasi eSPMI.
3. Masukkan username dan password Anda.
4. Klik tombol **Login**.
